# 金星満ち欠けカレンダー (Venus Phase Calendar)
[English](./README.en.md)
[**🌐 金星満ち欠けカレンダーを利用する**](https://gambaranai.github.io/Venus-Calendar/)

**金星満ち欠けカレンダー**は、金星の満ち欠け（位相）や見かけの大きさ、地球からの距離をリアルタイム・過去・未来にわたってインタラクティブに確認できる高精度な天体シミュレーション・カレンダーアプリです。

## 🌟 主な機能

- **金星の満ち欠けシミュレーション**  
  指定した日付の金星がどのように見えるか（三日月型、半月型、満月型など）をグラフィックで分かりやすく表示します。明けの明星・宵の明星の時期も直感的に確認できます。
- **軌道モデル（太陽・地球・金星）**  
  太陽系における地球と金星の位置関係を軌道図でシミュレーション。なぜ金星が満ち欠けするのか、視覚的に理解できます。
- **高精度な天体データ表示**  
  満ち欠けの割合（%）、見かけの等級、地球からの距離（天文単位: AU）、見かけの視直径など、詳細な天文データを自動計算します。
- **カレンダーとイベント検索**  
  カレンダー形式で日付を自由に選択可能。また、最大離角や内合・外合などの重要な天文イベントを簡単に検索できます。

## 🔍 なぜ「金星満ち欠けカレンダー」を作ったのか？

金星は地球から最も明るく見える惑星の一つであり、望遠鏡や双眼鏡を使うとガリレオ・ガリレイが発見したように「満ち欠け」や「大きさの変化」を観察することができます。
この**金星満ち欠けカレンダー**は、天体観測の計画を立てる方、宇宙や星空に興味がある方、学校の理科・天文学の学習用途など、様々な方に役立つツールを目指して開発されました。

## 🚀 使い方

1. 上記のリンクからアプリにアクセスします。
2. カレンダーから見たい日付を選択するか、「今日」ボタンを押します。
3. 画面中央の金星のグラフィックで、その日の金星の姿を確認できます。
4. 「🪐 軌道モデル」ボタンを押すと、地球と金星の軌道上の位置関係を見ることができます。
5. 下部のパネルで詳細な天文データや、次の主要なイベント（最大光度など）を確認できます。
